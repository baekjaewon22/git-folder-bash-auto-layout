Git 폴더 Bash 자동배치
=====================

기본 작업 폴더
- %USERPROFILE%\git

사용 방법
1. FourWindowWorkspace.exe를 실행합니다.
2. 사용자 홈의 git 폴더 아래 하위 폴더가 체크박스로 표시됩니다.
3. Git Bash로 열 폴더를 한 개 이상 체크합니다.
4. [선택 폴더 실행 + 전체화면 자동배치]를 누릅니다.
5. 선택한 폴더마다 Git Bash가 열리고, 작업표시줄을 제외한 전체 화면에 자동 배치됩니다.

배치 예시
- 1개: 전체 화면
- 2개: 좌우 2분할
- 3~4개: 2열 격자
- 5~6개: 3열 격자

다른 Git 상위 폴더 사용
- 상단 [찾아보기]에서 폴더를 선택합니다.
- 선택 경로는 다음 실행에도 유지됩니다.

바탕화면 아이콘
- 프로그램에서 [바탕화면 아이콘 만들기]를 한 번 누릅니다.

실행 파일 위치
- C:\Program Files\Git\FourWindowWorkspace\FourWindowWorkspace.exe
